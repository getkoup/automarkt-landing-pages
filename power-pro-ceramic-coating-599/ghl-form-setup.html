CSS and decorative HTML belong in different places. CSS goes in the form’s Custom CSS field; HTML goes in an HTML element. Create the input fields and submit button in GHL so the form retains CRM submission and validation.

Website-level Custom CSS cannot style fields inside a GHL iframe. The local landing page keeps the approved call/text buttons until a Power Pro form embed is supplied.
